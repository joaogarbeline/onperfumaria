Inconsistências encontradas

Coisas que já existem no código mas divergem entre si — vale decidir qual valor é o "certo" antes de crescer mais.

ink tem dois valores opostos tailwind.config.js define ink: #fafaf9 (quase branco), mas index.css define --color-ink: #171412 (quase preto) — o site inteiro usa o da variável CSS; o token do Tailwind parece não ser usado em lugar nenhum.
gold vs amber tailwind.config.js define gold: #d4af37, mas todo o resto do código (index.css e componentes) usa #d89a28 via --color-amber. São dois dourados ligeiramente diferentes coexistindo.
Toast de sucesso não usa o token --color-success Toast.tsx escreve as cores do estado de sucesso direto em hexadecimal (#bde4d4 / #eefaf5 / #0f8a5f) em vez de referenciar a variável já existente.
#FAF6EF ainda não é um token Usado no Header.tsx (texto do banner e fundo do campo de busca) mas não está declarado em index.css nem em tailwind.config.js — se for usado de novo em outro componente, vale formalizar.
